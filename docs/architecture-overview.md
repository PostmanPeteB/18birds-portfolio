# Architecture Overview

## High-level structure
18Birds is built as a modern web application with a React + TypeScript + Vite frontend, backed by Supabase for data, authentication, and access control, and deployed via Vercel.

## Core architectural themes
- Multi-tenant design
- Frontend-first product delivery
- Secure authentication and authorization
- Environment-aware deployment workflow
- Clear separation between UI concerns, auth logic, and data access

## Representative stack
- React
- TypeScript
- Vite
- Supabase
- Vercel
- GitHub

## Engineering priorities
- tenant isolation
- maintainable code structure
- secure-by-default decisions
- delivery speed without sacrificing clarity
- practical use of AI-assisted engineering workflows
